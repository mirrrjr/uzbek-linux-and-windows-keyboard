Linux va Windows uçun özbek klaviatura layouti

2023-yildagi alifbo yangilanişlarini va maxsus belgilarga tez kirişni özida jamlagan, tipografik jihatdan töğri özbek klaviatura layouti.

＃Layoutlar
5 ta Linux varianti
Uzbek (Standard)
Asosiy layout. Base va Shift qatlamlari oddiy US QWERTY, ya'ni hech narsani qayta örganişning hojati yöq. AltGr → Ş, Ç, Ö, Õ, Ğ, İ. AltGr+` → ʼ (tutuq belgisi). AltGr+' → ʻ (Oʻ/Gʻ da işlatiladi). Shuningdek, tire, « » burçakli qöştirnoqlar, egri qöştirnoqlar, yuqori indekslar va valyuta belgilari.
Uzbek (US)
Tarixan alohida variant bölgan; hozir Standard bilan bir xil, nomlar mos kelişi uçun saqlab qölingan.
Uzbek (2023)
2023-yildagi alifbo yangilanişi taklifiga asoslangan, AltGr kerak emas. W→Ş/ş, [→Õ/õ, ]→Ğ/ğ.
Uzbek (Programmer Dvorak)
Faqat Linux uçun. Base va Shift qatlamlari Programmer Dvorak (dvp) layoutiga mos keladi, ya'ni belgilar qatori va harflarning Dvorak'dagi joylaşuvi özgarmaydi. Özbekçaga xos harflar va tipografik qöşimçalar Standard dagi kabi AltGr da joylaşgan.
Uzbek (Cyrillic)
Özbek klaviatura layoutining kirill varianti.

02Örnatiş: NixOS

Bu repozitoriyni flake.nix faylingizga flake input sifatida qöşing: 

# flake.nix
{
  inputs = {
    ...
    # Add this line to your inputs
    uzbek-keyboard.url = "github:mirrrjr/uzbek-linux-and-windows-keyboard";
  }

  outputs = {
    ...
    # Add this line to your outputs
    uzbek-keyboard,
  } @ inputs:
  {
    nixosConfigurations."nixos" = nixpkgs.lib.nixosSystem {
      modules = {
        ...
        # Add this line to your modules
        uzbek-keyboard.nixosModules.module
      }
    }
  }
}

Keyin taqdim etilgan layoutlarni configuration.nix fayliga qöşib işlatişingiz mumkin: 

# configuration.nix
services.xserver.xkb.uz-enhanced.enable = true;
03Örnatiş: Windows

Xuddi şu Uzbek (Standard) layoutining Windows versiyasi ham mavjud, u Microsoft Keyboard Layout Creator yordamida yaratilgan. U Linux layoutini aynan takrorlaydi: asosi oddiy US QWERTY, özbek harflari, punktuatsiya va tipografik qöşimçalar esa AltGr da. Eslatma: Programmer Dvorak varianti hozircha faqat Linux uçun mavjud.

  1. Releases sahifasiga ötib, eng oxirgi setup.exe ni yuklab oling.
  2. Örnatuvçini işga tuşiring. Windows SmartScreen ogohlantirişi çiqişi mumkin, çunki örnatuvçi imzolanmagan; bu kiçik, erkin tarqatiladigan vosita uçun normal holat. More info → Run anyway ni tanlang.
  3. Settings → Time & Language → Language & Region ni oçing, tilingizni bosing → Options, keyin Add a keyboard ni bosib, Uzbek (AltGr) ni tanlang.
  4. Taskbar'dagi til indikatori yoki Win + Space orqali unga almaşing.
04Foydalaniş

Örnatişdan keyin tizimdan çiqib, qayta kirişingiz kerak bölişi mumkin. Keyin tizimingizning Settings → Keyboard (yoki Input Sources) bölimiga ötib, "Uzbek" ni qidiring va kerakli layout variantini qöşing (masalan, Uzbek (Programmer Dvorak)).
